# 柔術動画(BJJ動画管理Webアプリ)

Instagram・YouTubeの柔術動画を、URLと管理情報(技名・ポジション・技の種類・タグ・メモ)で整理するWebアプリです。
練習ノートで、どの動画を参考に練習したかを記録して振り返ることもできます。
カレンダーでは、練習・試合・セミナーなどの予定と、実際の練習記録を月ごとに確認できます。
iPhone Safariでの利用を最優先にした、シンプルなダーク系デザインです。

- 動画そのものは保存せず、URLと管理情報だけを保存します
- データはブラウザ内のIndexedDB(ブラウザに内蔵されたデータベース)に保存します
- ログイン不要。データはその端末・そのブラウザの中だけにあります

## 起動方法(自分のMacで開発するとき)

初回だけ、必要な部品(ライブラリ)をインストールします。

```bash
npm install
```

開発用サーバーを起動します。

```bash
npm run dev
```

Macのブラウザで http://localhost:5173 を開くと表示されます。

### iPhone Safariで確認する

1. MacとiPhoneを**同じWi-Fi**につなぎます
2. `npm run dev` を実行すると、ターミナルに `Network: http://192.168.x.x:5173/` のような行が表示されます
3. iPhoneのSafariでそのアドレスを開きます
4. 共有ボタン →「ホーム画面に追加」で、アプリのように起動できます

※ iPhoneで保存したデータはiPhoneのSafariの中に、Macで保存したデータはMacのブラウザの中に、別々に保存されます。
端末間でデータを移したいときは、設定 → バックアップでJSONを書き出し、もう一方の端末で復元してください。

## 画面構成

| 画面 | URL | 内容 |
|---|---|---|
| 動画一覧 | `#/` | 検索欄・絞り込み・動画カード。0件のときは空状態を表示 |
| 動画登録 | `#/new` | URL・技名(必須)、ポジション・技の種類・タグ・メモ・お気に入り(任意) |
| 動画詳細 | `#/videos/ID` | 元動画を開く・お気に入り・編集・削除・練習履歴・この動画で練習ノートを作成 |
| 動画編集 | `#/videos/ID/edit` | 登録済みの内容を引き継いで編集 |
| 練習ノート一覧 | `#/notes` | 練習日が新しい順。書きかけのノートがあれば「続きを書く」を表示 |
| 練習ノート作成 | `#/notes/new`(動画から作成時は `#/notes/new/動画ID`) | 練習日・関連動画・練習メモ・改善点・結果・練習回数 |
| 練習ノート詳細 | `#/notes/ID` | 内容の確認・関連動画へ移動・編集・削除 |
| 練習ノート編集 | `#/notes/ID/edit` | 保存済みの内容を編集 |
| カレンダー | `#/calendar/日付` | 月表示・前月/翌月・今日の表示。日付を選ぶとその日の予定と練習記録を表示し、予定・練習ノートを追加できる |
| 予定の登録 | `#/events/new?date=日付` | 種類・タイトル・開始日・終了日・時刻・場所・メモ |
| 予定の編集 | `#/events/ID` | 予定の編集・削除 |
| 設定 | `#/settings` | 分類管理・バックアップ・復元 |
| 分類管理 | `#/settings/positions` など | 追加・名称変更・削除・並べ替え(≡をドラッグ) |
| タグ管理 | `#/settings/tags` | タグの名称変更・削除 |
| バックアップ・復元 | `#/settings/backup` | JSONの書き出し・読み込み(置き換え/追加) |

## ファイル構成

```
src/
  main.tsx              アプリの起動
  App.tsx               画面の切り替え
  router.ts             URL(#/...)と画面の対応、戻る処理
  AppData.tsx           アプリ全体で共有するデータ(動画・分類・絞り込み条件)
  types.ts              データの型(Video, Category, PracticeNote, CalendarEvent など)
  styles.css            デザイン(色は先頭の変数でまとめて管理)
  storage/              ← データ保存処理(画面のコードから分離)
    repository.ts         保存処理の窓口。画面はここだけを使う
    indexedDbRepository.ts  IndexedDB版の実装
    db.ts                 データベースを開く処理・初期分類の登録
    backup.ts             バックアップJSONの形式と検証
    practiceDraft.ts      練習ノートの入力途中の内容(下書き)の自動保存
  utils/                URLチェック・日付表示・検索判定・ID生成・練習結果の表示名・カレンダーの日付計算
  components/           共通部品(カード・ダイアログ・アイコンなど)
  pages/                各画面
```

将来クラウド保存に切り替えるときは、`DataRepository` と同じ関数を持つ実装を作り、
`src/storage/repository.ts` の最後の1行を差し替えます。

## 仕様メモ

- **URL**:http/https で、Instagram(instagram.com)または YouTube(youtube.com / youtu.be)のURLのみ登録できます
- **サムネイル**:YouTubeはURLから自動で表示します。Instagramは認証なしで取得できないため代替表示になります。
  登録画面の「サムネイルを変更」から画像URLを手入力することもできます
- **タイトルの自動取得**:外部サービスの制限で安定して取得できないため実装していません(技名は手入力)
- **分類**:動画とはIDでつながっているので、名前を変えても動画の情報は壊れません。
  関連動画がある分類を削除するときは「未分類にする」か「別の分類に変更する」を選べます
- **検索**:技名・タグ・メモが対象です。スペース区切りで複数語を入力すると、すべてを含む動画を表示します
- **絞り込み**:ポジション・技の種類・お気に入りのみ・タグ(複数選択時はすべてを含む動画)を組み合わせられます
- **復元**:ファイル全体を検証してから書き込みます。書き込みは1回のトランザクション(全部成功か全部取り消し)で行うため、
  不正なファイルや途中失敗で既存データが壊れることはありません。
  「追加する」では同じIDの動画・練習ノートはスキップし、同じ名前の分類は既存の分類にまとめます。
  現在のバックアップはバージョン3(練習ノート・予定を含む)です。以前のバージョンのファイルも復元できます
- **練習ノート**:動画とは動画IDでつながっています。動画を削除してもノートは残り、「関連動画は削除されました」と表示します
- **下書きの自動保存**:練習ノートの入力内容は入力するたびに端末内(localStorage)へ自動保存されます。
  戻る・再読み込みをしても、次に開いたとき続きから入力できます。保存ボタンを押すか「入力内容を破棄」で下書きは消えます
- **カレンダー**:予定(練習・試合・セミナー・出稽古・その他)は種類ごとの色の点、実際の練習記録(練習ノート)は緑のチェックで表示します。
  練習ノートはカレンダー予定には複製せず、練習ノートの練習日をそのまま使って表示します(二重登録しません)。
  複数日の予定は期間中のすべての日に表示します(最長1年)。タイトルを空欄にすると種類名がタイトルになります
- **データの移行**:練習ノート追加時にバージョン2、カレンダー追加時にバージョン3へデータベースを更新しました。登録済みのデータはそのまま残ります
